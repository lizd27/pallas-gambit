# Pallas’ Gambit

Веб-платформа для гри в шахи онлайн, у якій класична гра поєднана зі стилістикою давньогрецької міфології. Фігури постають як міфологічні персонажі: король — Зевс, ферзь — Афіна, тура — Атлант, слон — Аполлон, кінь — Пегас, а пішаки — герої на чолі з Гераклом.

## Сторінки

- `index.html` — головна
- `create-game.html` — створення партії
- `game.html` — екран гри
- `learn.html` — навчання «12 подвигів Геракла»
- `level.html` — окремий рівень (подвиг)
- `heroes.html` — довідник героїв
- `progress.html` — «Мій прогрес»
- `404.html` — сторінка помилки

## Структура проєкту

- `css/` — стилі 
- `js/` — скрипти
- `images/` — логотип (`logo/`), фігури (`pieces/`), зображення героїв (`heroes/`), іконки (`icons/`)

## Як запустити

Відкрийте `index.html` у браузері. Окремий сервер не потрібен.
